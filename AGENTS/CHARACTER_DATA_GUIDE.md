# CHARACTER_DATA_GUIDE.md — 説明文からキャラ定義 JSON を作る手順

最終更新：2026-11-11

ゲーム画面の「バースト/アビリティ」タブの説明文から、`src/content/characters/<id>.json`（キャラ定義）を作るための手順書。
イヴ・ベートーヴェン・シャイターンの 3 体を作ったときに分かったことをまとめている。

| ファイル | 役割 |
|---|---|
| `AGENTS.md` §10 | 効果 DSL の部品と意味論（**部品の正しい定義はこちら**） |
| `DSL_PARTS.md` | 部品ごとの項目・値・例の一覧表 |
| `CHARACTER_DATA_GUIDE.md`（本ファイル） | 説明文の読み方、言い回しと部品の対応、確認が必要な項目 |
| `CHARACTER.md` | キャラごとの資料・確定状況・未確定事項・検証の記録 |
| `src/content/characters/<id>.json` | 定義そのもの（JSON を作った後はこちらが正） |

---

## 1. 作業の流れ

1. **画面を集める**：バースト/アビリティタブを上から下まで（スクロールして全部）スクリーンショットに撮る。説明文が要約になっている効果（「様々な効果を発動」など）は、**詳細ページ**の表も撮る。
2. **攻略記事を探す**：「〇〇に応じて」「様々な効果」のように、段階や中身が説明文に書かれていない効果は、攻略記事に段階表があることが多い。依頼者に頼んで内容をもらい、出典として `CHARACTER.md` に残す（アモン・アルテミス）。
3. **CHARACTER.md に節を作る**：ひな形（`CHARACTER.md` §0）に沿って、基本情報と「原文」の表を書く。説明文は**画面の文をそのまま**写す（言い換えない）。
4. **説明文を区切る**：§3 の記号のルールで、1 つの説明文を「効果」「条件」「回数上限」に分ける。
5. **部品に置き換える**：§4 の対応表で、区切った 1 つずつを DSL の部品にする。表にない言い回しは、AGENTS.md §10 の部品で組み立てる。組み立てられなければ `CHARACTER.md` §2「DSL で書けない効果」に記録する。
6. **説明文で決まらないことを洗い出す**：§5 の一覧を順に確かめ、決まらないものは仮置きにして `CHARACTER.md` の未確定事項に書く。クライアントに確認する。
7. **既定値を使ったことを伝える**：バーストゲージ UP の量など、「記載がなければ使う既定値」のうち**依頼者に伝えるもの**（§5 の表の「伝える」列）を使ったときは、どのキャラのどの効果で既定値を使ったかを依頼者に伝え、`CHARACTER.md` の未確定事項にも書く。
8. **JSON にする**：§6 の形にまとめて `src/content/characters/<id>.json` に保存する。`CHARACTER.md` の下書きは JSON への参照に置き換える（AGENTS.md §12）。
9. **確かめる**：§8 のチェックリストを通す。

## 2. 画面の項目と JSON の項目

| 画面 | JSON | メモ |
|---|---|---|
| キャラ名（例：[神代の始祖]イヴ） | `name` | 角かっこの肩書きも含めて画面どおり |
| SSR / MASTER などの表示 | （使わない） | MASTER は英霊の表示。種別は `kind`（神姫 `kamihime` / 英霊 `hero`） |
| 属性 | `element` | 画面のこのタブには出ないので、ステータスタブかクライアントに確認 |
| 「バースト」の行 | `burst` | `name` と `effects`。英霊は武器で変わるので `userDefined: true` を付け、`effects` には画面の効果（撮影時の武器のもの）を既定値として書く（AGENTS.md §4.2） |
| 「アビリティ」の行 | `abilities[]` | 画面の上から順に並べる |
| 「EX」の行（EX設定） | `abilities[]` に `ex: true` | 付け替えられるが、初期版は画面に付いているアビで固定（AGENTS.md §4.2） |
| 「アシスト」の行 | `assists[]` | 画面の上から順に並べる（同時に発動したときの処理順になる。AGENTS.md §6.1-2） |
| アビ名の「+」 | `name` に含める | 強化済みの表示。効果は画面の文どおりに書く |
| アイコンの枠の色 | `color` | 赤 `red` / 黄 `yellow` / 青 `blue` / 緑 `green` / 紫 `purple`。枠の色が判断しにくいときはクライアントに確認（シャイターンのアビ 1・3） |
| 使用間隔：N ターン | `ct: N` | 「0 ターン」は CT 0（何度でも使える。ベートーヴェンのアビ 1） |
| 効果時間：N ターン | 付与する効果の `duration: { "turns": N }` | アビ全体ではなく、そのアビが付けるバフ・状態の持続 |
| 習得 Lv / 強化 Lv | （使わない） | |
| ★性能 UP、※発動回数に応じて性能 UP | （使わない） | ダメージの強さだけなので無視する（クライアント確認） |

## 3. 説明文の区切り方

画面の説明文は、記号で区切られた短い文の並び。まず記号で区切ってから、1 つずつ部品にする。

| 記号・形 | 意味 | 書き方 |
|---|---|---|
| `/` | 効果の区切り | `effects` の別の要素にする |
| `・` | 効果の区切り（同じ対象・同じ条件のことが多い） | `effects` の別の要素にする |
| `※` | 直前の効果への**注記**。条件・回数上限・常時効果・強化のどれか | 下の「※ の読み方」で判断する |
| `（累積可）` `（累積）` | 重ねがけできるバフ | `stack`（AGENTS.md §7.1） |
| `（特大）` `（極大）` | ダメージの大きさ | `note` に残す（ダメージ量は計算しない） |
| `（専用／必中／累積／6T）` | デバフの枠・命中・累積・持続 | 専用 → 専用の `slot`、累積 → `stack`、6T → `duration: { "turns": 6 }`、必中 → `note` |
| `減衰 40 万` | ダメージ上限の減衰 | `note` に残す |
| `〇〇時、` `〇〇の度` | 発動のきっかけ | アシストの `trigger`（§4.3） |

**※ の読み方**

| ※ の後ろ | 例 | 書き方 |
|---|---|---|
| 回数上限 | ※同一ターンに 15 回まで発動 | アシストの `limit: { "perTurn": 15 }` |
| アビの使用回数の上限 | ※同一ターンに 1 回まで使用可能 | アビの `limit: { "perTurn": 1 }` |
| 条件で変わる効果 | ※15 回以上で HP・状態異常回復を追加 | 効果の中の `if`（§4.5） |
| 回数で変わる効果 | ※奇数回発動時〇〇／偶数回発動時△△ | `if` と `useCount` の `parity`（§4.5） |
| 即リキャとコスト | ※バーストゲージ 20 消費して 2 回まで再使用可能 | `cost` と `recast`（§4.6） |
| アビの常時効果 | ※シュイドオラアドを発動する度、再使用間隔 2 ターン短縮 | アシストの項目に分ける（`origin.kind: "ability"`。§4.7） |
| 持続の延長 | ※発動する度効果ターン延長（最大 5 ターン） | `duration.turns` を数値の部品で（§4.5） |
| 強化 | ★性能 UP、※発動回数に応じて性能 UP | 無視する |

## 4. 言い回しと部品の対応表

例の列は、実際に作った 3 体（イヴ・ベートーヴェン・シャイターン）から取っている。

### 4.1 ダメージ

| 言い回し | 部品 | 例 |
|---|---|---|
| 敵全体に雷属性ダメージ | `damage`、`target: "allEnemies"`、`category` はアビなら `ability`・バーストなら `burst` | イヴ アビ 1 |
| 雷属性ダメージ（特大）（バーストの先頭） | `damage`、`category: "burst"`、`note: "特大"` | イヴ・シャイターンのバースト |
| 全属性ダメージ | 属性ごとに `damage` を 7 つ、**説明文（または詳細ページ）の順**に並べ、各 `element` を指定 | イヴ アビ 2（幻 → 火 → 水 → 風 → 雷 → 闇 → 光） |
| 敵ランダムに 5 回 | `damage`、`target: "randomEnemy"`、`hits: 5` | ベートーヴェン アビ 1 |
| 発動する度に回数増加（最大 10 回） | `hits: { "useCount": { "ability": "self", "scope": "battle", "kind": "activated" }, "min": 1, "max": 10 }` | イヴ アビ 1 |
| 紅の譜面の数 × 6 回のダメージ | `hits: { "token": { "name": "紅の譜面" }, "mul": 6 }` | ベートーヴェン アシスト 2 |

- 区分は、アビの効果なら `ability`、バーストなら `burst`。アシストのダメージで区分が書かれていないときは `ability` で仮置きし、未確定事項に書く。
- 属性は**キャラの属性と同じなら書かない**（自動で付く）。キャラと違う属性、または全属性のときだけ `element` を書く（AGENTS.md §4.1、§10.2）。
- **ヒット数は、断りがなければ 1**（クライアント確認）。「〇回」「〇ヒット」と書かれているときだけ `hits` を変える。

### 4.2 対象

| 言い回し | 部品 |
|---|---|
| 自分、自身 | `"self"` |
| （対象が書かれていない。「アビリティ再使用間隔 1 ターン短縮」など） | `"self"`（自分のこと） |
| 味方全体 | `"allAllies"` |
| 自分以外の味方全体 | `{ "alliesWhere": { "excludeSelf": true } }` |
| 雷属性キャラ（効果を受ける側） | `{ "alliesWhere": { "element": "thunder" } }` |
| 敵全体／敵単体／敵ランダム | `"allEnemies"` / `"enemy"` / `"randomEnemy"` |

### 4.3 きっかけ（アシストの `trigger`）

| 言い回し | 部品 | 例 |
|---|---|---|
| ターン終了時 | `{ "event": "turnEnd" }` | イヴ アシスト 2、ベートーヴェン アシスト 2 |
| 〇〇がアビリティを**使用**した時 | `{ "event": "abilityUsed", "filter": {...} }` | |
| 〇〇を**発動**する度 | `{ "event": "abilityActivated", "filter": { "ability": "<アビ ID>" } }` | シャイターン アビ 3 の常時効果 |
| 味方全体が赤色アビリティ使用時 | `{ "event": "abilityUsed", "filter": { "color": "red" } }` | シャイターン アシスト 1 |
| 自分以外の自属性キャラが使用した | `"filter": { "sourceElement": "thunder", "source": "others" }` | ベートーヴェン アシスト 1 |
| 雷属性キャラが（使用した） | `"filter": { "sourceElement": "thunder" }`（自分も含む） | イヴ アシスト 1、シャイターン アシスト 2 |

**「使用」と「発動」は必ず読み分ける**（AGENTS.md §4.7）。

| 言葉 | 数えるもの | 入るもの |
|---|---|---|
| 使用 | `abilityUsed` | プレイヤーがアビを使ったときだけ |
| 発動 | `abilityActivated` | 使ったときと、バースト・アビ・アシストの効果でアビが発動したとき |

例：イヴのバーストは「ラグナロクテンペストを発動」。この発動は、アビ 1 の「発動する度に回数増加」には入るが、イヴのアシスト 1 の「赤色アビリティを使用」には入らない。

### 4.3b トークン・発動回数・パーティのきっかけと条件
| 言い回し | 部品 |
|---|---|
| 〇〇付与時（トークン） | `trigger: { "event": "tokenAdded", "filter": { "token": "〇〇", "source": "self" } }` |
| 〇〇を N 個獲得時 / N 個獲得以降 | `count` の `tokenAdded`、`"sum": "amount"`、`scope: "battle"`。「獲得時」は `eq`、「以降」は `gte` |
| 消費した〇〇の数に応じて / N 個以上消費している場合 | `count` の `tokenConsumed`、`"sum": "amount"`、`scope: "battle"` |
| 〇〇が N の時（所持数） | `token` 条件（`gte` / `eq`） |
| （アシストの）N の倍数回目発動時 | 効果の中の `if` に `count` の `assistTriggered`（`filter: { "assist": "<自分の ID>" }`）、`multipleOf` |
| N の倍数ターン終了時 | `trigger: turnEnd`、`cond: { "turnCount": { "multipleOf": N } }` |
| サブメンバー含む雷属性キャラ | `{ "alliesWhere": { "element": "thunder", "includeSub": true } }` |
| サブメンバー時にも発動 | アシストの `activeIn: "both"` |
| パーティ全体が雷属性キャラの場合 | `{ "partyAll": { "element": "thunder" } }` |
| 戦闘中に 1 回のみ使用可能 | アビの `limit: { "perBattle": 1 }` |
| 〇〇時（状態中）、1 ターン内に N 回まで使用可能（状態になる前の使用は数えない） | 非表示のトークン（`hidden: true`）を「状態中に使った回数」のカウンターにする。使うたびに `addToken`、ターン開始時（`turnStart`）に `consumeToken` の `"all"` で 0 に戻す。「このターンの使用回数」で数えると状態になる前の使用まで入ってしまうため（シャイターン アシスト 1） |
| 〇〇に応じて同一ターンに使える回数が増える（段階表がある） | 使用条件 `usable` に `or` で「段階に届いている かつ 今ターンの使用回数（`useCount`、使う前なので今回を含まない）が上限未満」を並べる（アルテミス アビ 1） |
| 〇〇を N 回発動 | `repeat`（`times: N`）の中に `activateAbility` |
| 状態異常を全回復 | `removeDebuff`、`count: "all"` |
| 消去不可 | `"undispellable": true` |
| 〇〇の数に応じて〇〇 UP（効果量が段階で変わる。段階表がある） | 一度だけ付けるもの（バーストの効果など）は `switch` で段階ごとの `amount` を書く（大きい段階を上に）。常時効果は、段階に届いた瞬間（トークンが `eq` で段階の境目になったとき）に永続のバフを付け直す。効果量が大きくなるので同じ枠の上書きで入れ替わる（アモン バースト・アシスト 1） |
| 〇〇の数に応じて〇〇 UP（段階表がない） | `addBuff` の `amount: null`、`note` に「〇〇の数に応じて」 |
| 発動回数に応じてヒット数が増える（段階表がある） | `switch` で発動回数（`useCount`、`kind: "activated"`）の段階ごとに `hits` を書く。ダメージ上限は `note` に残す（アモン アビ 2） |
| 〇〇の回数に応じて〇〇を N 回発動（段階表がある） | `switch` で段階ごとに `repeat`（`times: N`）の中に `activateAbility` を書く（アモン アシスト 1） |

### 4.4 回数の条件

| 言い回し | 部品 | 例 |
|---|---|---|
| ターン中に〇〇が 5 回赤色アビリティを使用した場合（5 回ごと） | アシストの `cond` に `{ "count": { "event": "abilityUsed", "filter": {...}, "scope": "turn", "multipleOf": 5 } }` | イヴ アシスト 1、シャイターン アシスト 2 |
| 〇〇の使用回数が 15 回以上で〇〇を追加 | 効果の中の `if` に `{ "count": { ..., "gte": 15 } }` | イヴ アシスト 2 |
| 同一ターンに N 回まで（アシスト） | `limit: { "perTurn": N }`。**発動回数**の上限（クライアント確認） | イヴ アシスト 1（10 回） |
| 同一ターンに N 回まで使用可能（アビ） | アビの `limit: { "perTurn": N }` | ベートーヴェン アビ 3（1 回） |

- 「〜する度」「〜回ごと」は `multipleOf`。「〜回〜した場合」は、その回数ちょうどで 1 回だけか、N 回ごとかが文からは決まらないので確認する（イヴ アシスト 1 は 5 回ごとだった）。
- 「ターン中に」「同一ターンに」は `scope: "turn"`、「戦闘を通して」は `scope: "battle"`。書かれていなければ確認する（イヴのアビ 1 は戦闘全体だった）。

### 4.5 分岐

| 言い回し | 部品 | 例 |
|---|---|---|
| 〇〇なら △△ を**追加** | `if`（`then` だけ）。基本の効果は `if` の外に書く | イヴ アシスト 2 |
| 奇数回発動時〇〇／偶数回発動時△△ | `if` の `cond` に `useCount` の `parity: "odd"`、`kind: "activated"`。`then` と `else` | イヴ アビ 3 |
| 所持している〇〇によって効果が変わる（どれか 1 つ） | `switch`（上から最初に当てはまった 1 つだけ） | ベートーヴェン アビ 1 |
| N 個以上で〇〇、M 個以上で△△（段階が積み重なる） | `if` を並べる（当てはまったものを全部実行） | ベートーヴェン アシスト 2 |
| 発動毎に紅・黄・蒼・翠の順に | `switch` と `useCount` の `mod: { "by": 4, "eq": ... }` | ベートーヴェン アビ 4 |
| 〇〇の数に応じて回数増加 | `repeat`、`times` に数値の部品 | ベートーヴェン アシスト 2 |
| 発動する度効果ターン延長（最大 5 ターン） | `duration: { "turns": { "useCount": {..., "kind": "activated"}, "max": 5 } }` | シャイターン アビ 1 |
| リミッター解除時〇〇 | `cond` に `{ "hasStatus": { "target": "self", "status": "リミッター解除" } }` | シャイターン アシスト 1 |

`if` と `switch` の使い分けを間違えると結果が変わる。「どれか 1 つ」なら `switch`、「当てはまるもの全部」なら `if` を並べる。

### 4.6 CT・即リキャ・コスト

| 言い回し | 部品 | 例 |
|---|---|---|
| 再使用間隔を N ターン短縮 | `changeCT`、`amount: -N` | イヴ アシスト 1、シャイターン アビ 2 |
| 〇〇が即座に使用可能に | `changeCT`、`setTo: 0` | シャイターン アシスト 2 |
| 自分の他のアビリティを即座に使用可能に | `changeCT`、`abilities` に他のアビの ID、`setTo: 0` | シャイターン アビ 1 |
| 自分以外の味方全体のアビリティ再使用間隔を〇〇の数だけ短縮 | `changeCT`、`target: { "alliesWhere": { "excludeSelf": true } }`、`amount` に数値の部品 × -1 | ベートーヴェン アビ 3 |
| バーストゲージ 20 消費して 2 回まで再使用可能 | `cost`（`useCount` の `gte: 1` のときゲージ 20）と `recast`（`useCount` の `lte: 2`） | イヴ アビ 2 |
| 〇〇時、1 ターン内に 3 回まで使用可能に | アシストの項目（使用時に、条件を満たし今ターン 2 回目までなら `changeCT setTo 0`） | シャイターン アシスト 1 前半 |

- **コストの `when` は使う前に評価する**ので、`useCount` に今回の使用は入らない。**効果の中**では今回の使用が入る（AGENTS.md §6）。
- 即リキャの書き方は種類によって違う（AGENTS.md §6「即リキャ」）。説明文だけでは「何回目からコストがかかるか」「CT が戻るのは何回目までか」が分からないことが多いので、§5 で確認する。

### 4.7 アビの発動・常時効果・アシストの分割

| 言い回し | 部品 | 例 |
|---|---|---|
| 〇〇を発動（バースト・アシストの効果） | `activateAbility`。使用回数には数えない、CT は変わらない | イヴ・シャイターンのバースト、シャイターン アシスト 1 |
| アビの説明文の「※〇〇する度△△」（アビを使わなくても働く） | アシストの項目に分け、`origin: { "kind": "ability", "id": "<アビ ID>" }` | シャイターン アビ 3 |
| 1 つのアシストに、きっかけや回数上限が違う部分が `/` で並ぶ | 部分ごとにアシストの項目を分け、`origin: { "kind": "assist", "index": N }` | シャイターン アシスト 1 |
| アシスト 2 と同じ効果を発動（別のアビから） | `sharedEffects` に 1 回だけ書き、`useEffects` で参照 | ベートーヴェン アビ 2 |

### 4.8 バフ・デバフ・状態・トークン・ゲージ

| 言い回し | 部品 | 例 |
|---|---|---|
| 味方全体の〇〇 UP | `addBuff`（`buff` に画面の名前、`slot` に枠 ID、`amount` に実数値） | |
| 〇〇 UP（累積可） | `addBuff` に `stack`。1 段ずつ別々に切れるなら `duration: "perStack"` | イヴ アビ 2 |
| 敵全体の〇〇 DOWN | `addDebuff` | ベートーヴェン アシスト 2 |
| サステイン付与、リミッターを解除、防壁 | `addStatus`（効果量のない状態） | イヴ アビ 3、シャイターン アビ 1 |
| 状態異常を N つ回復 | `removeDebuff`、`count: N` | イヴ アシスト 2 |
| HP 回復 | `heal`（記録だけ） | |
| 味方全体のバーストゲージ UP | `gaugeUp`。量が書かれていなければ `amount` を省略する（既定 +20）。**記載がなかったことを依頼者に伝える** | イヴ アビ 3（+20）、ベートーヴェン アシスト 2（+10、専用武器で +15） |
| 自身に〇〇を付与（譜面・旋律など） | 固有トークン。`tokens` に定義し、`addToken` | ベートーヴェン |
| 〇〇を全て消去 | `consumeToken`、`amount: "all"`（グループごとなら `group`） | ベートーヴェン アシスト 2 |
| 合計で 3 つまで（4 つ目以降は破棄） | `tokenGroups` に `max: 3` | ベートーヴェンの旋律 |
| 専用武器があれば〇〇 | キャラの `options` と条件 `option` | ベートーヴェン |
| アイテムの生成（キュアボトルなど） | `custom`（何もしない）と `note` | ベートーヴェン アシスト 2 |

- `slot`（枠 ID）は `src/content/buffSlots.json` の一覧から選ぶ。同じ効果の枠がないときだけ新しい ID を一覧に足す（キャラ専用の「専用」デバフは `<キャラ ID>_<内容>`）。キャラごとに勝手な ID を作ると、同じ枠の重複（上書き・MISS）が判定されなくなる。
- `buff` の名前は**画面の言葉どおり**にする（「バーストダメージプラス」を「バーストダメージ UP」にしない）。同じ名前の累積型バフは重ねがけされるため、名前が違うと別のバフになる。
- 効果量が分からないバフは `amount: null`。推測で数値を入れない（AGENTS.md §7.2）。

## 5. 説明文だけでは決まらないこと（必ず確認する）

**断りがないときの既定値**（クライアント確認。説明文に書かれていないときはこれを使う）

| 項目 | 既定値 | 依頼者に伝える |
|---|---|---|
| ゲージ上限 | 100 | 不要 |
| バースト時の消費 | 100 消費（`subtract100`） | 不要 |
| ダメージのヒット数 | 1 | 不要 |
| ダメージの属性 | キャラの属性 | 不要 |
| バーストゲージ UP の量 | +20（`gaugeUp` の `amount` を省略） | **伝える**（「〇〇のアビ〇のゲージ UP は量の記載がなかったので +20 にした」） |

- 「伝える」ものは、JSON では `amount` を**省略**して書く（+20 と数字で書かない）。省略していれば、後から「記載がなかった効果」を JSON から探せる。量が分かったら数字を書く。

画面の説明文には書かれていないが、チャートの計算に効くもの。上ほど計算への影響が大きい。

| 項目 | なぜ要るか | 3 体での実例 |
|---|---|---|
| **バーストゲージ UP の量**（記載がなければ +20 にして依頼者に伝える） | ゲージの計画（フルバースト）に直接効く | イヴ アビ 3：+20、ベートーヴェン アシスト 2：+10（専用武器 +15）、シャイターン アシスト 2：+20 |
| **「使用」と「発動」のどちらか** | カウンターの数え方が変わる | イヴ アビ 1 は「発動する度」、アビ 3 は「奇数回発動時」 |
| **回数を数える範囲**（ターンか戦闘全体か） | 書かれていないことがある | イヴ アビ 1 の n は戦闘全体 |
| **即リキャの細かい挙動** | 何回目からコストか、何回目まで CT が戻るか | イヴ アビ 2：2 回目以降ゲージ 20、即リキャは 1 ターン 2 回まで |
| **効果でアビを発動したときの CT** | 発動で CT が変わるか | イヴのバーストのアビ 1 発動：CT は変わらない |
| **消費の有無** | トークンが残るかどうか | ベートーヴェン アビ 2・3：消費しない |
| **効果の処理順** | 同じアシスト内で、ゲージ UP とダメージの順など | ベートーヴェン アシスト 2：蒼 → 黄 → 翠 → 紅 |
| **周期・上限に達した後** | 順番が一巡した後、上限で捨てられた後 | ベートーヴェン アビ 4：5 回目は紅に戻る。譜面が破棄されても追加効果は出る |
| ゲージ上限・バースト時の消費 | **断りがなければ上限 100・100 消費**（クライアント確認）。「上限 200」「全消費」と書かれているときだけ変える | 3 体とも上限 100 |
| アビの色 | アイコンの枠の色が判断しにくい | シャイターン アビ 1・3：黄 |
| ヒット数 | **断りがなければ 1 ヒット**（クライアント確認）。多段の記載がある場合だけ確認する | 3 体とも記載のないダメージは 1 ヒット |
| 持続ターン | 「効果時間」が書かれていない効果 | イヴ アビ 3：すべて 2 ターン |
| 累積の上限と持続の扱い | 段ごとに切れるか | イヴ アビ 2：上限なし、1 段ずつ別々 |
| 効果量 | 重複判定（MISS・上書き） | 多くが不明（`null` のまま） |

確認した結果は `CHARACTER.md` の「検証の記録」に日付付きで残す。

## 6. JSON の形

```json
{
  "id": "eve",
  "name": "神代の始祖イヴ",
  "kind": "kamihime",
  "element": "thunder",
  "gaugeMax": 100,
  "burstConsume": "subtract100",
  "options": [],
  "burst": { "name": "破滅の雷+", "effects": [] },
  "tokenGroups": [],
  "tokens": [],
  "abilities": [
    { "id": "eve_a1", "name": "ラグナロクテンペスト+", "color": "red", "ct": 1, "effects": [] }
  ],
  "assists": [
    { "id": "eve_assist1", "name": "ミシックプレビレッジ", "trigger": {}, "cond": {}, "limit": {}, "effects": [] }
  ],
  "sharedEffects": {},
  "source": "出典と日付"
}
```

- ID の付け方：キャラは英小文字（`eve`、`beethoven`、`shaitan`）。アビは `<キャラ ID>_a<番号>`、アシストは `<キャラ ID>_assist<番号>`。分けたアシストは `<キャラ ID>_assist<番号>_<内容>`、アビの常時効果は `<キャラ ID>_a<番号>_passive`。
- 並び順：`abilities` と `assists` は画面の上から順（アシストの処理順に効く）。
- 使わない項目（`options`・`tokens`・`sharedEffects` など）は省略してよい。

## 7. 作業例

### 7.1 イヴ アビ 2「クルーエルディザスター+」

画面：
> 敵全体に全属性ダメージ・味方全体のダメージ上限UP(累積可)※バーストゲージ20消費して2回まで再使用可能★性能UP
> 使用間隔：5ターン　効果時間：2ターン

1. 区切る：①敵全体に全属性ダメージ ②味方全体のダメージ上限 UP（累積可） ③※即リキャとコスト ④★性能 UP
2. ① → 属性ごとの `damage` を 7 つ（順番は確認：幻 → 火 → 水 → 風 → 雷 → 闇 → 光）
3. ② → `addBuff`、`stack`、効果時間 2 ターン。累積の上限と、段ごとに切れるかを確認（上限なし、段ごと）
4. ③ → 「2 回まで再使用可能」「20 消費」の意味を確認（1 ターン 2 回まで、そのターンの 2 回目以降にゲージ 20）→ `cost` と `recast`
5. ④ → 無視
6. 使用間隔 5 → `ct: 5`

### 7.2 シャイターン アシスト 1「バハルタフリール」

画面：
> リミッター解除時シュイドオラアドが1ターン内に3回まで使用可能に/味方全体が赤色アビリティ使用時シュイドオラアドを発動※同一ターンに15回まで発動

1. `/` で 2 つに分かれ、きっかけも回数上限も違う → **アシストの項目を 2 つに分ける**（`origin.kind: "assist"`）。
2. 前半：きっかけはアビ 2 の**使用**、条件は「リミッター解除中」と「今ターンの使用が 2 回目まで」、効果はアビ 2 の CT を 0。
3. 後半：きっかけは味方の赤アビの**使用**、効果はアビ 2 を**発動**（`activateAbility`）、`limit.perTurn: 15`（※の回数上限は後半だけにかかる）。

### 7.3 シャイターン アビ 3「ジャースウサハム」

画面：
> 味方全体の急所攻撃確率UP(累積可)※シュイドオラアドを発動する度再使用間隔2ターン短縮

- 前半はアビを使ったときの効果 → アビの `effects`。
- ※の後ろは、アビ 3 を使わなくても、シュイドオラアドが発動するたびに働く → **アシストの項目**（`origin: { "kind": "ability", "id": "shaitan_a3" }`、きっかけは `abilityActivated`）。
